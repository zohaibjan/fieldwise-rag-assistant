# Fictional document control policy

This policy is synthetic demonstration content.

## Superseded manuals
Mark a superseded manual as archived in the training register. The FieldWise reference index replaces the older searchable chunks when a document with the same filename is re-ingested. Its SHA-256 content version lets a reviewer identify the exact indexed text.

## Missing information
When a specification is absent, ask the training supervisor for an approved document. Do not infer torque values, live operating limits or emergency instructions from these fictional examples.

## Access
The demonstration workbench is single-user and local. A production service needs authentication, document permissions, audit controls and a separate approved retention policy.
